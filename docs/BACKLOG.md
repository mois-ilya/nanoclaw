# Бэклог NanoClaw

## Mini App: экран «Что сейчас происходит» (детерминированное состояние)

Владелец хочет в «Кабинете» видеть базовое текущее состояние без обращения к LLM: только чтение из БД хоста,
nanogate и Podman, без генерации.

- Все расписания (кроны и повторяющиеся задачи) всех агентов: кто, что, когда следующий запуск, последний результат.
  Сейчас «Задачи» показывают задачи одного пользователя, а у владельца нужен общий список.
- Отложенные дела: одноразовые напоминания, ожидающие запуска, и `process_after` в сессиях.
- Что работает прямо сейчас:
  - контейнеры агентов: чей, с какого времени, текущий ход (turn), последний шаг из телеметрии;
  - очередь `NC_MAX_CONTAINERS`;
  - фоновые задачи хоста (sweep, бэкап, digest).
- Незавершённое: ход, ожидающий ответа на вопрос (ask_question); задачи провижининга (`nc_jobs`); неотправленные
  исходящие сообщения.
- Коннекторы и сервисы: nanogate, STT, Tailscale (exit node онлайн или нет), последний бэкап.

Принципы: только чтение, обновление по pull-to-refresh, без содержимого переписки (метаданные), для друзей
показывать только их собственное.
